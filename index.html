Pokedex (ASP.NET)

A Pokédex website with all 151 Generation I Pokémon. Users can collect Pokémon, build teams, and battle.

C# ASP.NET Web API EF Core SQLite JWT JavaScript

This is a Pokédex website with all 151 Generation I Pokémon. Users can make an account, search for Pokémon, and save them in their own collection. They can build teams of up to six Pokémon and make them battle in the Battle Arena. Past battles are saved, so users can look at their results later. It is built with ASP.NET, SQLite, and a secure login.

Purpose

The purpose of Pokédex (ASP.NET) is to make browsing and collecting Pokémon fun and organized in one place. It also lets users play with their collection through teams and battles. For us, it was a way to practice building a full-stack web app with a secure login system and a REST API.

Key features

  • Register, login, and forgot password with an email reset link (JWT-based)
  • Browse all 151 Generation I Pokémon with search and type filtering
  • Animated Pokéball cards that reveal each Pokémon when clicked
  • My Collection: catch and manage your own Pokémon
  • My Teams: build teams of up to 6 Pokémon
  • Battle Arena with a battle log and speed controls
  • Battle History to review past battles
  • Trainer profile with avatars (Ash, Misty, Brock, Jessie, James, Nurse Joy)
  • Welcome banner with Gen I overview cards

TaskFlow Ai

A task manager web app where users can sign up, log in, and add, edit, and delete their daily tasks. Built with Flask and SQLite

Python Flask SQLite HTML/CSS

TaskFlow AI is a task manager web app that helps users organize their daily work in one place. Each user creates an account and logs in to see only their own tasks. They can add new tasks, view them in a list, open the full details, and edit or delete them anytime. Tasks can be marked as done, and the whole list can be exported to a CSV file.

Purpose

The purpose of TaskFlow AI is to help people keep track of their tasks without using paper notes or scattered reminders. It gives users one simple place to plan, update, and finish their work. It also let our group practice building a full web app with a login system and a database.

Key features

  • Secure signup and login, with a separate account for each user
  • Add new tasks with a title and description
  • View all tasks in one organized list
  • Open a task to see its full details
  • Edit or delete tasks anytime
  • Mark tasks as done to track progress
  • Profile page with photo upload
  • Export tasks to a CSV file
